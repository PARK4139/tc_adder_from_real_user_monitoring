# Setup > Preferences > General 검수 TC

각 TC는 [검수 대기 폴더](../../../../sqa/tc/to_review/setup/preferences/general/)와
[검수 완료 폴더](../../../../sqa/tc/reviewed/)에서 관리합니다. 파일 위치가 검수 상태입니다.
이 문서는 안내이며 TC 본문의 정본이 아닙니다.

- [파일 작성·관리 방법](../../../../sqa/tc/README.md)
- [화면·기능 혼합 Suite 구성](suites.md)
- [공유 검수 웹](http://172.20.13.185:9999/tc-up-validation/)

검수 웹은 두 상태 폴더의 개별 파일을 읽고 수정·추가·이동·삭제를 자동 반영합니다.
표시 순서는 `configs/tc_review.json`에서 관리합니다.
현재 TC는 시나리오 초안이며 실제 실행 결과가 아닙니다.
